# Hockey Sim

The app for Hockey Sim: today's NHL games, standings and a scorecard for
everyone, and for signed-in members projected goalies, lineups, game
simulations, a sportsbook comparison and bet tracking.

Open https://shawnzamperini.github.io/hockey-sim/ in Safari on an iPhone and
tap **Share → Add to Home Screen**.

This repository is only the app's screens. The model that powers it (ratings
and simulation engine) runs on a private server; this page has no model code
or ratings in it. Data comes from the NHL's public API by way of an hourly job.

The files here are published from the private model repository; edits made
directly here will be overwritten.
